Date arithmetic that never changes the date you passed in

calends is a set of small functions for adding, comparing, rounding and formatting calendar dates. Every function takes a Date and returns a new one. Adding a month to 31 January gives you the end of February, not March.

Install

npm install calends
// each function is a named export
import { add, startOf, diff, format } from "calends";

const d = new Date(2026, 10, 12);

add(d, { months: 3 });   // new Date, d is untouched
d.getMonth();            // still 10

Reference

Every row below uses the same starting date: d = new Date(2026, 10, 12), Thursday 12 November 2026. Weeks start on Monday unless you pass weekStartsOn.

Add and subtract

Units: years, months, weeks, days. Months clamp to the last day of the target month.
CallReturns
add(d, { days: 30 })2026-12-12
add(d, { months: 3 })2027-02-12
add(d, { years: 1, days: 1 })2027-11-13
subtract(d, { years: 1 })2025-11-12

Start and end of

Units: week, month, quarter, year. endOf returns the last day, not the last millisecond.
CallReturns
startOf(d, "week")2026-11-09
startOf(d, "quarter")2026-10-01
endOf(d, "month")2026-11-30
endOf(d, "year")2026-12-31

Compare and measure

diff(a, b, unit) counts whole units from b to a. Calendar days, so a daylight saving change never makes a day 23 or 25 hours long.
CallReturns
diff(new Date(2027, 0, 1), d, "days")50
diff(new Date(2027, 0, 1), d, "months")1
isBefore(d, new Date(2026, 11, 1))true
isSame(d, new Date(2026, 10, 30), "month")true

Parse and format

Tokens: YYYY MM DD D MMM ddd. parse accepts YYYY-MM-DD only and throws on a date that doesn't exist.
CallReturns
format(d, "YYYY-MM-DD")"2026-11-12"
format(d, "ddd D MMM YYYY")"Thu 12 Nov 2026"
parse("2026-11-12")Date, 12 Nov 2026, local midnight
parse("2026-02-30")RangeError: 2026-02-30 is not a date

Where Date goes wrong

These are the cases calends was written for. The left column is what the built-in Date does with the obvious code.

IntentBuilt-in Datecalends
31 Jan 2026 plus one month
x.setMonth(x.getMonth() + 1)		 2026-03-03 2026-02-28
29 Feb 2024 plus one year
x.setFullYear(2025)		 2025-03-01 2025-02-28
30 Feb 2026
new Date(2026, 1, 30)		 2026-03-02, no error throws RangeError
Tomorrow, keeping the original
d.setDate(d.getDate() + 1)		 d is now tomorrow d unchanged, new Date returned
Every example on this page uses local time. calends has no time zone handling.
