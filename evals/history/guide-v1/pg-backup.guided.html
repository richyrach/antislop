pgferry Source on GitHub

Carries a Postgres database across to S3.

pgferry is an open-source command line tool. One command takes a backup of your database and puts it in your bucket. Another brings it back.

Postgresyour database
backup →← restore
S3 bucketyour storage
Get pgferry from the repository

Two commands, one in each direction

Run --help on either command to see its options.
CommandCarriesDirection
pgferry backup A copy of the database Postgres → S3
pgferry restore A copy from the bucket S3 → Postgres

Run it from cron

A backup is a single command, so any scheduler can run it. This line would run it at 03:00 every night.

# add the options shown by: pgferry backup --help
0 3 * * * pgferry backup

Read the code

The source is public. Check what it does with your database before you point it at one, and open an issue if something is wrong.
