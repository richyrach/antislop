Postgres in. S3 out.

pgferry is an open-source command line tool. It dumps a Postgres database and carries the file to an S3 bucket.

See a run Install

One command per crossing

Give pgferry a database URL and a bucket path. To go the other way, give it the bucket path and a target database.

Example commands
# back up
$ pgferry backup postgres://app@db.internal/orders s3://my-backups/orders/

# restore
$ pgferry restore s3://my-backups/orders/latest postgres://app@db.internal/orders_copy

Put it on the timetable

pgferry is a command, so cron, systemd timers and CI schedulers can run it. These are cron lines.

02:00
0 2 * * *

Every night.

Hourly
0 * * * *

At the top of every hour, for databases that change all day.

Sun 03:30
30 3 * * 0

Once a week, on Sunday.
