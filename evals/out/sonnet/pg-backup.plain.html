Ferry your Postgres data
to S3, safely.

pgferry is a small command-line tool that streams PostgreSQL backups straight to Amazon S3 (or any S3-compatible store). Compressed, encrypted, and verifiable, with no temp files and no glue scripts.

Get started View on GitHub
$ brew install pgferry/tap/pgferry 
# back up a database to S3
$ pgferry backup postgres://app@db.internal/orders s3://acme-backups/orders
→ connecting to db.internal ... ok
→ streaming pg_dump | zstd | age | s3 ... 4.2 GiB → 812 MiB
→ verifying checksum ... sha256 match
✓ done in 1m 48s  s3://acme-backups/orders/2026-11-12T03-00-00Z.dump.zst.age

# and bring it back
$ pgferry restore s3://acme-backups/orders --latest postgres://app@staging/orders

Built for boring, reliable backups

Everything you need to trust your backups, and nothing you have to babysit.

🌊

Streaming, no temp files

Data flows from Postgres to S3 through a pipe. You don't need spare disk the size of your database.

🔐

Client-side encryption

Encrypt with age or a KMS key before anything leaves your machine. S3 only ever sees ciphertext.

🗜️

Fast compression

zstd by default, with gzip available. Multipart uploads run in parallel to saturate your link.

✅

Verify every backup

Checksums are recorded and checked on upload. Run pgferry verify to test-restore into a scratch database.

♻️

Retention policies

Keep the last N backups, or daily, weekly, and monthly sets. Old objects are pruned automatically.

🧩

S3-compatible

Works with AWS S3, Cloudflare R2, Backblaze B2, MinIO, and Wasabi via a custom endpoint.

Up and running in three steps

From install to a scheduled, verified backup in a couple of minutes.

Install

$ brew install pgferry/tap/pgferry
# or
$ go install github.com/pgferry/pgferry@latest

Configure

Use environment variables or a small config file. AWS credentials are picked up from the standard chain.

$ export PGFERRY_AGE_RECIPIENT=age1qyq...
$ export AWS_REGION=us-east-1

Back up and schedule

# nightly at 03:00
0 3 * * * pgferry backup $DATABASE_URL s3://acme-backups/orders --keep-daily 7 --keep-weekly 4

Command reference

A small surface area that's easy to remember.

CommandWhat it does
pgferry backupDump a database and stream it to S3.
pgferry restoreRestore a chosen or latest backup into a target database.
pgferry listList backups for a prefix with size, age, and checksum.
pgferry verifyTest-restore a backup into a scratch database and report.
pgferry pruneApply retention rules and delete expired backups.

FAQ

Quick answers to common questions.

Which Postgres versions are supported?

pgferry wraps pg_dump and pg_restore, so it supports the versions those tools support. Use a client version equal to or newer than your server.

Does it support point-in-time recovery?

No. pgferry takes logical backups. For PITR, use WAL archiving tools alongside it. pgferry is ideal for portable, easy-to-restore snapshots.

Will it lock my database?

No. Backups use a consistent snapshot via pg_dump, which doesn't block normal reads and writes.

How do I lose the encryption key safely?

You shouldn't. Store your age identity in a password manager or secrets vault. Without it, encrypted backups can't be restored.

Can I contribute?

Yes. Issues and pull requests are welcome on GitHub. Check the contributing guide for setup instructions.
