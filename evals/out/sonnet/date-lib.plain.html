Quick start

Import only what you use. Every function returns a new value and never mutates its input.

// 1. Install
// npm install tempo-date

import { format, add, diff, isBefore } from 'tempo-date';

const start = new Date('2026-11-12');

format(start, 'MMMM D, YYYY');     // "November 12, 2026"
add(start, { weeks: 2 });         // Date: 2026-11-26
diff(add(start, { days: 10 }), start, 'days'); // 10
isBefore(start, new Date());      // boolean

Why Tempo

Built for the cases that make up 95% of date code.

Tiny by design

Each function is its own module, so bundlers ship only the code you call.

Immutable

No surprise mutations. Inputs are never modified, so state updates stay safe.

Native Date compatible

Works with plain Date objects. No wrapper classes to learn or unwrap.

Locale aware

Month and weekday names come from Intl, so there are no locale bundles to load.

API overview

The full surface area, in one table.

FunctionDescriptionReturns
parse(str)Parse an ISO 8601 string into a Date.Date
format(date, pattern)Format a date using tokens like YYYY-MM-DD.string
add(date, duration)Add years, months, weeks, days, hours, minutes or seconds.Date
sub(date, duration)Subtract a duration from a date.Date
diff(a, b, unit)Whole-unit difference between two dates.number
startOf(date, unit)Snap to the start of a day, week, month or year.Date
isBefore(a, b)Compare two dates. Also isAfter, isSame.boolean
